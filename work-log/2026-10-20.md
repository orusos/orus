## Decisions

- Files and Image Viewer browse `$HOME`, not the `~/.orus` sandbox; Image Viewer opens on `~/Pictures`. A sandbox boundary is an open item.
- The bar, dock and launcher are layer-shell surfaces in a separate process (`orus-linux --panel`) because a window covering the shell window hides anything drawn inside it. The dock surface is full width and never resizes: resizing a layer surface made labwc drop the pointer's focus, so the visible part is set with an input region instead.
- The launcher key is Super+Space, sent to the panel over `$XDG_RUNTIME_DIR/orus-panel.sock` by `orus-linux --toggle-launcher`. labwc turns its default keybinds off once any are defined, so the session lists Alt+Tab, Alt+Shift+Tab and Alt+F4 itself.
- Calamares' own English translation wins over a branding translation, so the welcome page's two texts cannot be set from branding. `orus-brand-welcome` patches a copy of the welcome module's library on the installed machine (two strings, padded with zero bytes) and `modules-search` lists that copy first.
- Media: a new `linux-media` crate (GStreamer `playbin` per element, `appsink` for BGRA frames) behind `media-gstreamer`. Capture sources can be fixed with `DETIR_CAMERA_SOURCE` and `DETIR_MICROPHONE_SOURCE` for machines without devices. An app needs `media.camera.capture` and `media.microphone.capture` in its `waid-package.json` `capabilities`, or the page gets `NotAllowedError`.

## Findings

- The web runtime never reads the media host's event queue (`poll_events`), on any platform: `ended`, `canplay` and `durationchange` do not reach the page.
- `getUserMedia` and `enumerateDevices` return nothing for an origin without the capture capability; that is the capture-authority wrapper, not the backend.
- The Calamares license page paints its accept box pale red until ticked with an inline style that a stylesheet cannot override; the sheet only sets the checkbox text color for each state.
